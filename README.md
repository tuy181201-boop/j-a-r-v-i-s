## О проекте

**J.A.R.V.I.S.** — это учебный open-source проект, цель которого — собрать собственного голосового ассистента, похожего по духу на J.A.R.V.I.S. из фильмов Marvel.

Это **не копия персонажа** и не попытка повторить вымышленный ИИ. Это практический проект о том, как собрать модульную систему, которая умеет:

- слушать пользователя;
- распознавать речь;
- понимать запрос;
- выполнять полезные действия;
- отвечать голосом.

Проект находится на ранней стадии. Сейчас в репозитории есть документация и план развития, но ещё нет рабочего кода ассистента.

## Идея

Типичный голосовой ассистент работает как конвейер:

```text
Голос пользователя
        │
        ▼
┌──────────────────┐
│ STT: речь → текст│
└──────────────────┘
        │
        ▼
┌──────────────────┐
│ LLM: понимание   │
│ запроса и ответ  │
└──────────────────┘
        │
        ▼
┌──────────────────┐
│ TTS: текст → речь│
└──────────────────┘
        │
        ▼
Голосовой ответ
